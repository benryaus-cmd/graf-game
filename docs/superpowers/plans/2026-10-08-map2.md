# Map 2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, with a fresh whole-change reviewer at the end.

**Goal:** Deliver a cosy local Map 2 with separate art, night-ready lights and height-based building tiers.

**Architecture:** Map ID selects a deterministic district layout/content provider inside the current chunk stream. A building-tier policy controls detailed roots and shared proxy batches. React remounts one WorldScene on map changes; Map 2 blocks public-room joins.

**Tech Stack:** Existing React, TypeScript, Three.js, Node 22; no new runtime dependencies.

**Spec:** docs/superpowers/specs/2026-10-08-map2-design.md

## Global Constraints
- Preserve Map 1 saved IDs and storage keys.
- Map 2 is local-only; no backend changes.
- Nine 48 m chunks, 144 × 144 m district; shared assets and no shadows/bloom.
- Four real street lights maximum, plus player light.
- Two-metre overlap and fallback until a real replacement exists.

## Review Focus
- Map changes during paint/save/decode or multiplayer teardown.
- Tall/short threshold and reversed/zero range inputs.
- Missing detail or model results after chunk disposal.
- Hidden retained geometry incorrectly suppressing a proxy.
- Night lights/poles inside buildings or inadequate walking-route coverage.
