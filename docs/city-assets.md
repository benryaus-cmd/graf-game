# City visual improvement options

Keep the existing world geometry and graffiti UVs. Start by replacing the shared stone ground texture with distinct asphalt/concrete tiles, then add brick/stucco variations to selected walls. Use shared 512–1024px textures and a small material pool; avoid per-piece materials and heavy multi-map PBR on phones.
